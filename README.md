# 🛒 Product Listing App

A modern, responsive e-commerce product discovery application built with **React** and **Vite**, powered by the **Fake Store API**.

## ✨ Features

- **Explore Products**: Browsing a wide variety of products from the Fake Store API.
- **Dynamic Search**: Instantly find products by title using a real-time search bar.
- **Category Filtering**: Narrow down products by categories like Electronics, Jewelery, Men's Clothing, and Women's Clothing.
- **Detailed Product View**: Deep dive into product specifications with a dedicated details page.
- **Shopping Bag**: Add items to your cart and manage them with ease (persists in LocalStorage).
- **Responsive Design**: Seamless experience across mobile, tablet, and desktop devices.
- **Dark Mode Support**: Elegant dark theme for a better viewing experience.

## 🛠️ Tech Stack

- **Framework**: [React.js](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS / Tailwind CSS (Optional)
- **State Management**: React Context API
- **Routing**: React Router DOM
- **API**: [Fake Store API](https://fakestoreapi.com/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16.x or later)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd proton-assignment
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
